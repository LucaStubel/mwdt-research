# Changelog

## 2026-09-27 — Release 1.0

- Small-cluster inference: wild cluster restricted bootstrap (R12; Rademacher weights, B = 9,999, seed 2027). Top-10 share p = .0515 (515/9,999; clustered p = .024); reported in README and abstract.
- Abstract wording tightened for accuracy (pbpstats exports rather than "every lineup", truncation described as hitting the export cap, near-identity, future work on prior shared experience); final pass toward more conventional, less rhetorical wording.
- Confirmatory vs. exploratory analyses labelled in README.
- Pinned dependency versions; added 9 reproducibility tests and a GitHub Actions workflow that rebuilds all results from raw data.
- Added `DATA_DICTIONARY.md` (column definitions, third-party data licensing) and `CITATION.cff`.

## 2026-09-23 — Reproducibility audit

This release makes every number in the README reproducible from the code and data in this repository. Several figures reported in earlier drafts changed as a result.

### Corrections to reported results

| Item | Earlier draft | Now | Reason |
|---|---|---|---|
| H1 coefficient | β = .1235 ("paper units", MWDT ÷ 3.5) | b = .035 per clock-minute | .1235 was the coefficient on *uncentered* MWDT in the quadratic model (slope extrapolated to MWDT = 0). The ÷3.5 conversion had no basis and has been removed. |
| H1 R² | .386 | .379 | .386 belonged to the quadratic model. |
| H2 | Inverted U supported, p = .018 | Diminishing returns; inverted U not supported | Lind–Mehlum test: slope at sample maximum −.001, p = .48. Turning point CI 238–463 min. |
| H4 | "2.5× stronger than traditional tenure"; tenure n.s. alongside MWDT (p = .218) | Not supported within sample | Meta-analytic ρ is not comparable to a single-sample r. Roster continuity r = .449 vs. MWDT .506 (Williams p = .52); continuity significant in every model. |
| H3 | b = .000215 per min, N = 475 | b = .177 per 1,000 min, N = 477 | Rebuilt from repo data with prior PPG matched from `nba_stats_clean.csv`; SEs clustered by player. Personal MWDT shown to equal 4 × minutes played. |
| Movers test | b = .000329, p = .016, N = 141 | b = .310 per 1,000 min, p = .024, N = 122 | Mover now defined reproducibly from dyad files (no overlap between season-1 and season-2 teams). |
| Highest MWDT | NYK 2023-24 | NYK 2022-23 | Checked against dyad files. NYK 2023-24 MWDT = 193.4. |
