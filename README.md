## Motivation

Team familiarity research usually measures tenure at the roster level: how long the average member has been on the team, or how long the group has existed as a unit. Across 169 studies, those measures correlate only weakly with performance (meta-analytic ρ = .08 to .20; Gonzalez-Mulé et al., 2020).

Transactive memory theory (Wegner, 1987) locates familiarity somewhere else: in relationships between specific people. A guard knows how *this* center rolls. A surgeon coordinates with *this* anesthesiologist (Reagans, Argote & Brooks, 2005). If the mechanism is dyadic, the measure should be dyadic too. In Kozlowski & Bell's (2003) terms, familiarity is a compilational construct, and averaging it across a roster may discard the structure that matters.

This repository builds dyad-level familiarity measures from NBA lineup data and tests how they relate to team and player performance. It also reports what the data do *not* support, so that others can build on the measure with accurate expectations.

## The Metric

```math
\text{MWDT} = \frac{\sum_{i \lt j} \text{minutes}(i,j)}{N_{\text{pairs}}}
```

- $\text{minutes}(i,j)$ = regular-season game-clock minutes players *i* and *j* shared the floor
- $N_{\text{pairs}}$ = number of distinct player pairs that shared any minutes

**An important property.** Every minute of basketball puts exactly 10 pairs on the floor, so the numerator is close to constant across teams (coefficient of variation 3.4%). MWDT is therefore very nearly *constant / N_pairs*: r(MWDT, 1/N_pairs) = .994 (Figure 4). In practice MWDT measures **how few player pairs a team used**, i.e. rotation size. The analysis tests whether it carries anything beyond that.

**Top-10 pair share** — the fraction of a team's pair-minutes held by its 10 most-used pairs — is a concentration measure that varies partly independently of rotation size (r with N_pairs = −.69).

**Harmonized measures (primary specification).** pbpstats exports at most 500 lineups per team, sorted by minutes. 59 of 90 team-seasons hit that limit and lose many very short lineups (up to ~14% of a season's minutes). Because truncation is more likely for disrupted teams, all primary measures use only lineups of at least 3 minutes, which are complete for every team. All-lineup versions are reported as robustness checks (R7).

## Results

OLS with standard errors clustered by franchise (30 clusters; key tests also use a wild cluster restricted bootstrap, R12); controls for payroll, average age, roster continuity and conference; MWDT mean-centered. N = 90. Full output: [`results/team_level_results.txt`](results/team_level_results.txt), [`results/player_level_results.txt`](results/player_level_results.txt).

| | Prediction | Result | Key statistics |
|---|---|---|---|
| **H1** | MWDT → team Net Rating | Supported as an association | r = .52; b = .034 per minute (SE .007), p < .001; +1 SD (58 min) ≈ +2.0 Net Rating; R² = .407 (controls only .298) |
| **H2** | Inverted U | Diminishing returns, no downturn | b(MWDT²) = −.00019, p = .002; turning point 342 min (95% CI 272–413); Lind–Mehlum slope at sample max = −.012, p = .24 |
| **H3** | Season-1 personal MWDT → season-2 PPG | Supported, but measures playing time | b = .18 PPG per 1,000 min, p = .007, N = 477, controlling for prior PPG; personal MWDT = 4 × minutes played |
| **H4** | MWDT stronger than traditional tenure | Not supported within sample | r(MWDT) = .52 vs r(roster continuity) = .45; Williams test p = .42; both significant in the joint model |
| **Movers** | Carryover survives a team change | Supported (playing-time interpretation) | b = .31 per 1,000 min, p = .024, N = 122; MWDT × Mover interaction p = .13 |

**Confirmatory vs. exploratory.** H1–H4 and the movers test were stated before the analyses in this repository were run. The rotation-size identity is a mathematical property of the metric. Everything involving Top-10 pair share, partner concentration and the harmonized threshold was added after inspecting the data and is **exploratory**: it should be treated as a hypothesis for new seasons, not as a confirmed finding.

### Robustness: rotation size

| Model (DV = Net Rating, all controls) | Key coefficient | p |
|---|---|---|
| R1: MWDT + N_pairs | MWDT b = −.017 | .30 |
| R4: MWDT net of 1/N_pairs + 1/N_pairs | residual MWDT b = .006 | .94 |
| R5: Top-10 pair share + N_pairs | b = 16.8 (+1 SD ≈ +1.2 Net Rating) | .024 |
| R7c: same, all lineups (not harmonized) | b = 19.5 | .007 |
| R9: R5 + export-truncation dummy | b = 15.5 | .068 |
| R11: R5 with Spotrac payroll for all 90 | b = 18.3 | .020 |
| R12: R5, wild cluster bootstrap (small-cluster inference) | t = 2.25 | .052 |

**Reading.** The H1 association is carried almost entirely by rotation size: once the number of pairs is controlled, MWDT adds nothing. Among teams that used a similar number of pairs, those concentrating more minutes in their top 10 pairs tended to perform better (clustered p = .02; wild cluster bootstrap p = .052), but this estimate weakens when also controlling for export truncation, a proxy for how many lineups a team used (clustered p = .07; bootstrap p = .14). The concentration result is suggestive, not established; it is exploratory and was not a pre-stated hypothesis.

### Player level

Personal MWDT is mathematically four times minutes played, so H3 and the movers test show that players who played more last season score more this season beyond their prior scoring. A minutes-independent measure (share of a player's shared minutes with his four most frequent partners) is weakly associated with next-season PPG (b = 2.5, p = .043; exploratory).

## Limitations

1. **MWDT is nearly a function of rotation size.** It cannot, on its own, separate "these pairs know each other well" from "this team used few players." Rotation size is shaped by injuries, depth and roster quality, so H1 is not evidence for a transactive-memory mechanism.
2. **Reverse causality.** Healthy, good teams can keep tight rotations. A lagged test (MWDT last season → Net Rating this season) was not significant in an earlier analysis (p = .38, N = 60).
3. **The concentration result is fragile** (p = .007 to .14 depending on specification and inference method) and exploratory.
4. **Export truncation.** 59 files hit pbpstats' 500-lineup limit; the harmonized measures address this, but lineups under 3 minutes are excluded for all teams.
5. **Player identification.** pbpstats ShortName contains surnames only. Same-surname players are merged in dyad files (e.g. Kawhi and Meyers Leonard in 2022-23). A re-export with player IDs is planned.
6. **Pair-level familiarity is not new.** Huckman, Staats & Upton (2009) average prior joint projects over pairs; Reagans, Argote & Brooks (2005) and Espinosa et al. (2007) use pairwise experience. The contribution here is showing what that aggregation measures in continuous-lineup sports, not the idea of pairwise familiarity itself.
7. **Sample.** 30 teams × 3 seasons; 30 clusters is a modest number.

## Reproducing the Analysis

```bash
pip install -r requirements.txt
python notebooks/01_mwdt_calculation.py       # ~2 s, writes mwdt_team_ranking.csv
python notebooks/02_regression_analysis.py    # team level, writes results/ and figures/
python notebooks/03_h3_individual_carryover.py # player level
python notebooks/04_sloan_abstract_exhibits.py # Table 1 and Figure 1 of the abstract
python sloan/build_pdf.py                      # rebuilds the abstract PDF
pytest -q tests                                # 9 reproducibility tests
```

Dependencies are pinned in `requirements.txt` (Python 3.12). A GitHub Actions workflow (`.github/workflows/reproduce.yml`) rebuilds every result from the raw lineup files and runs the tests on each push. Column definitions and data licensing are in [`DATA_DICTIONARY.md`](DATA_DICTIONARY.md).

Run the scripts from the repository root. `00_data_collection.py` re-scrapes player stats and is not needed to reproduce the results.

Script 01 rebuilds all dyads and team measures from the raw lineup files in `data/raw/lineups/`.
